# Сайт театральной мастерской "Чердак Хофнарра"

## О проекте
Проект включает в себя серверную часть и клиентскую и предназначен для получения информации о театральной мастерской.
Создано:
- Дмитрий Бычков
- Дмитрий Тян

## Установка и запуск
Серверная часть
```bash
cd server
node create-admin.js [password]
npm i
npm run start
```

Клиентская часть (дебаг)
```bash
cd client
npm i
npm run dev
```
