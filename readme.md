# Сайт университетской театральной студии "Чердак Хофнарра"

## О проекте
Проект включает в себя серверную и клиентскую часть, и предназначен для получения информации о театральной студии.
Создано:
- Дмитрий Бычков
- Дмитрий Тян

## Установка и запуск
Серверная часть
```bash
cd server
node create-admin.js [password]
npm i
npm run start
```

Клиентская часть (дебаг)
```bash
cd client
npm i
npm run dev
```
